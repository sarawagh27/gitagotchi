# Security Policy

## Supported Versions

We release patches and bug fixes for the current active release of Gitagotchi.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

The security and privacy of users' credentials and GitHub tokens are taken very seriously.

> [!NOTE]
> Gitagotchi never transmits, stores, or logs any personal access tokens or secret tokens. Secrets are passed strictly in memory and automatically redacted in all error handlers.

If you discover a security vulnerability within Gitagotchi, please report it privately:

1. **GitHub Security Advisory (Preferred)**:
   Navigate to the repository's [Security tab](https://github.com/sarawagh27/gitagotchi/security) and click **Report a vulnerability**.
2. **Email**:
   Alternatively, contact the maintainer directly at [sarawagh27@users.noreply.github.com](mailto:sarawagh27@users.noreply.github.com).

### What to include in your report:

- A description of the vulnerability and its potential impact.
- Clear step-by-step instructions or proof-of-concept to reproduce the issue.
- Any suggested fixes or mitigations.

### Response Timeline

- We will acknowledge receipt of your vulnerability report within **48 hours**.
- We will provide regular updates on progress toward resolving the issue.
- Once a fix is verified, a patched release will be published and credit will be given in the release notes (unless anonymity is preferred).
